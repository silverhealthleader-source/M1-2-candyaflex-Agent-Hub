# M1-2 동료평가 제출 체크리스트

평가 대상은 강사 워크스페이스 `/education`입니다. 전체 허브의 외부 링크 목록과 구분해 아래 기능을 한 애플리케이션에서 시연합니다.

| 필수 결과물 | 평가자가 확인할 동작 | 제출 증빙 |
|---|---|---|
| AI 채팅 | 자연어 질문, 로딩, 현재 저장 데이터 요약을 반영한 실제 GPT 답변 | 질문+답변+DATA CONTEXT 화면 |
| 데이터 CRUD | 날짜·시간(value)·메모 추가, 목록 갱신, 수정·삭제 | 시연용 기록의 저장·수정 결과 화면 |
| 대화 기록 | 자동 저장, 목록, 특정 대화 전체 메시지 불러오기 | 대화 목록과 복원 완료 화면 |
| 배포·문서 | Vercel·Render 접속, Swagger, README 실행·환경변수 | 배포 주소·Swagger·실행환경 README |

## 설명 자료

- 시계열 100개 이상, 기간·개수·평균·최대/최소·추세를 서버에서 계산하는 흐름
- 라우터 / 서비스 / Pydantic / 저장소의 분리 기준
- Firestore data·conversations의 CRUD와 원본 보존 삭제
- 요약 JSON을 시스템 지시문에 주입하는 원리
- CORS·개인 접속 보호·서버 환경변수·키 관리의 차이

상세 설명은 [과제 점검 문서](assignment-review.md)에 있습니다.

## 선택 보너스

Function Calling과 별도 stdio MCP 클라이언트의 읽기 전용 요약 호출, 그래프·추가 지표·JSON 내보내기·다크 모드를 확인합니다. [도구 연동 문서](tool-integration.md)에 스키마·호출 근거·단계를 제공합니다. MCP 또는 GPT Actions 중 하나이면 되므로 GPT Actions를 추가로 만들 필요는 없습니다.

## 제출 순서

1. 공개 GitHub 주소, Vercel 강사 화면, Render API, Swagger 주소를 제출란에 입력합니다.
2. 비공개 제출 ZIP에서 README와 세 가지 필수 화면을 확인합니다.
3. 실제 운영자료가 담긴 ZIP은 강사가 승인한 비공개 제출 경로로 전달합니다. 접속 키를 공개 소스나 캡처에 넣지 않습니다.
4. 개인 접속 키 없이 접근하면 401이 정상입니다. 평가 시 연결된 화면을 직접 시연하거나 권한이 있는 비공개 방식으로 접근을 제공합니다. 공개 공용 키를 만들지 않습니다.
5. 무료 서버 첫 연결이 늦으면 안내에 따라 재시도합니다. 제출 직전 정상 접속을 확인합니다.

추가 교재 수집과 다중 사용자 기능은 필수 채점 항목과 구분합니다. 파일·문서 준비 완료와 실제 평가 사이트 업로드 완료는 서로 다른 단계입니다.
