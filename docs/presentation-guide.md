# 동료평가 발표 웹사이트

주소: https://candyaflex-edu-agent-hub.vercel.app/presentation

1. 전체 허브의 ‘동료평가 발표’ 또는 강사 화면 왼쪽 ‘동료평가 발표 슬라이드’를 누릅니다.
2. 상단에서 전체 설명 18장 또는 필수 시연 10장을 선택합니다.
3. 다음·이전 버튼이나 좌우 방향키로 이동합니다. Home·End는 처음·마지막 장입니다.
4. ‘발표자 메모’ 또는 N으로 말할 내용·직접 할 동작·확인할 결과를 엽니다. ‘목차’로 특정 설명에 바로 이동합니다.
5. ‘실제 화면 실행’을 누르면 배포 애플리케이션을 시연 창에서 조작할 수 있습니다. 미연결이면 창 안의 연결 설정에 기존 개인 접속 키를 입력합니다. 키는 기존 사이트 탭 세션에만 보관합니다.
6. F 또는 ‘전체 화면’으로 발표합니다. ‘발표 준비’의 인쇄 기능은 18장 전체를 가로형으로 출력하며 브라우저 인쇄에서 PDF로 저장할 수도 있습니다.

## 실제 캡처와 개인정보

공개 배포에는 운영 수치·캡처를 포함하지 않습니다. ‘발표 준비’에서 기존 비공개 제출 ZIP의 screenshots PNG 13장을 선택하면 해당 장에 실제 화면과 버튼 위치의 빨간 테두리를 표시합니다. 이미지는 File API와 Blob URL로 브라우저 메모리에만 표시하며 서버로 전송하지 않습니다. 새로고침 후에는 다시 선택합니다.

별도 비공개 발표 ZIP에는 실제 캡처가 들어 있습니다. 압축을 모두 풀고 `index.html`을 열면 인터넷 없이 슬라이드와 캡처를 볼 수 있습니다. 실제 기능 시연·현재 데이터 조회에는 인터넷과 기존 접속 권한이 필요합니다. 공개 웹에서 내려받은 HTML만으로 개인 운영자료가 나타나지는 않습니다.

4장의 ‘연결된 교육 요약 불러오기’는 현재 탭의 기존 접속 키로 보호된 요약 API를 읽습니다. 데이터를 변경하거나 GPT를 호출하지 않습니다. 현재 수치의 조회 시점을 표시합니다. 기존 실행 캡처는 2026-10-24의 증빙으로 구분합니다.

## 발표 구성

- 1~3장: 소개, 필수 네 가지 결과물, 5분 시연 순서
- 4~6장: 시계열 준비, 현장 데이터 기준, 라우터·서비스·저장 분리
- 7~8장: 실제 채팅 시연, 시스템 지시문 컨텍스트 주입
- 9~11장: CRUD와 대화 복원 시연
- 12~13장: Swagger·배포, Pydantic·Firestore·CORS·키 관리
- 14~16장: Function Calling·MCP, 통계·내보내기·다크 모드, 월별 수업·교재
- 17~18장: 자동 테스트와 실서비스 검증의 구분, 마무리·질의응답

MCP는 별도 stdio 클라이언트 검증이며 영구 호스트 설치를 뜻하지 않습니다. 필수 기능, 선택 보너스, 사용자 확장 요청을 구분합니다. 시연용으로 추가한 기록만 수정·삭제하고 실제 교육기록은 시험 대상으로 선택하지 않습니다.

## 복사해서 바로 붙여넣기

- 7장 ‘질문 복사’를 누르고 실제 채팅 입력창을 클릭해 Ctrl+V로 붙여넣습니다. 전송은 입력을 확인한 뒤 직접 누릅니다.
- 9장은 교육명·오늘 날짜·1시간·메모를 항목별로 복사합니다. 교육 방식은 ‘기타’를 직접 선택하고 교육생 수는 0으로 둡니다.
- 10장은 2시간과 수정 메모를 복사할 수 있습니다.
- 실제 시연 창 위에도 같은 복사 버튼이 있어 창을 닫지 않고 항목을 차례대로 붙여넣습니다.
- 14장은 MCP 설치·검증 명령어를 각각 복사합니다. 프로젝트 루트의 PowerShell에 붙여넣고 기존 비공개 환경변수를 준비합니다.
- 발표자 메모에는 현재 장의 발표문·시연 순서 복사 버튼이 있습니다. Swagger 시연 창에는 공개 문서 주소 복사가 있습니다.

성공하면 ‘복사 완료’가 표시됩니다. 브라우저가 자동 복사를 제한하면 내용을 선택한 직접 복사 창이 열리며 Ctrl+C를 사용합니다. 복사 기능은 API 호출·데이터 저장·질문 전송·키 복사를 하지 않습니다.
