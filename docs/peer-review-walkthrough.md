# 동료평가: 실제 시연과 증빙을 확인하는 7단계

공개 코드·README 검토는 설계 검토입니다. 실제 배포 시연과 비공개 실행검증은 별도로 확인합니다. 기존 사전평가 61%와 동료의 문서 기반 예비 추정 점수는 서로 다른 기준이며, 어느 것도 보완 후 공식 재평가 점수가 아닙니다.

## 평가 전 접속 준비

1. 강사가 [Vercel 강사 화면](https://candyaflex-edu-agent-hub.vercel.app/education)을 엽니다. 입장 인증번호는 강사가 화면에 직접 입력합니다.
2. 교육 화면의 **연결 설정**에서 기존 개인 API 접속 키를 연결합니다. 사이트 입장 번호와 API 접속 키는 서로 다릅니다. OpenAI 키·Firebase JSON은 이 칸에 입력하지 않습니다.
3. **대시보드 → 전체 기간**을 선택하고 연결 상태와 요약을 확인합니다. 특정 연도는 전체 저장 건수보다 적을 수 있으므로 100건 기준을 전체 기간에서 확인합니다. 계획·폐강·대체 일정은 실적에 합산하지 않습니다.
4. [Render health](https://candyaflex-edu-api.onrender.com/health)와 [Swagger](https://candyaflex-edu-api.onrender.com/docs)를 미리 엽니다. 첫 연결 지연 시 안내에 따라 기다린 뒤 재시도합니다.
5. 원격 평가자는 비공개 제출 ZIP의 `동료피드백-보완결과.md` → `실행검증-최신.md` → `screenshots/` 순서로 봅니다. 비공개 ZIP과 입장 번호를 공개 이슈·README에 올리지 않습니다. 실시간 접근 권한을 받지 못한 경우는 **미확인**으로 기록합니다.

독립 재현은 README의 가상 120건과 Firestore 에뮬레이터 절차를 따릅니다. 이는 운영 DB 검증과 구분하고 실제 GPT에는 평가자 본인의 비공개 API 키를 사용합니다. 공용 평가 키나 인증 우회 경로는 제공하지 않습니다.

## 7개 현장 검증

| 순서 | 실제로 실행할 동작 | 통과를 판단할 근거 |
|---|---|---|
| 1. 데이터 준비 | 전체 기간 요약과 목록 확인 | 목록 총건수와 summary.count가 같고 100 이상. 기간·합계·평균·최대/최소를 목록과 대조. 생성 스크립트만으로 DB 저장을 증명하지 않음 |
| 2. CRUD | 교육 실적 관리에서 `[평가 임시]` 기록 1건 추가 → 목록 확인 → 시간 1→2 수정 → 삭제 | 건수 +1, 총시간 +1→+2→기준값 복원. 삭제 후 활성 목록에서 제외. 원본 교육기록은 편집하지 않음 |
| 3. GPT 답변 | 강사 AI 비서에서 아래 질문 전송 | 로딩 후 실제 답변, 기간·건수·수치가 같은 기간 요약과 일치, 자동 저장 표시. health.ai_configured만으로 대체하지 않음 |
| 4. 대화 복원 | 새로고침 → 이전 대화 기록 → 방금 질문의 **대화 이어가기** | 같은 질문과 답변 전체 재표시. 목록 API는 제목/메타데이터, 상세 API는 전체 messages. 단순 목록 표시와 구분 |
| 5. Swagger·검증 | 필수 API 메서드 확인. 본인 로컬 가상 자료에 잘못된 value=-1 요청 | `/docs`·`/openapi.json` 접속, 필수 10개 메서드, 저장 전 422. Swagger Authorize에는 개인 API 키를 비공개로 입력 |
| 6. 배포·UX | 실제 Vercel에서 요약·채팅·목록 이동, 새로고침 | Render API 연동, 로딩/저장 표시. 실패 시 입력 복원과 미저장 안내. 잠금 화면 200/302는 인증 후 서비스 성공 증거가 아님 |
| 7. 문서·보안 | README 실행 절차·환경변수·증빙 시각 확인 | 공개 파일에 비밀값/운영 원본 없음. 자동 테스트·실제 HTTP·Firestore 직접 조회·GPT 생성 시각을 구분 |

채팅에서 사용할 질문:

```text
현재 전체 실적의 기록 건수, 총 교육시간, 기록 1건당 평균, 최댓값과 최솟값을 알려주세요. 계획은 제외하고 실제 요약 수치만 근거로 답해주세요.
```

새로고침 후 대화를 불러와도 분석 연도는 현재 선택값입니다. 질문에 사용한 기간과 화면에서 비교하는 기간을 같게 맞춥니다. 브라우저 새로고침 검증과 새로운 HTTP 클라이언트의 상세 조회 검증은 서로 다른 항목입니다.

## 읽기 전용 재검사

키는 명령행 인수에 넣지 않고 기존 `.env` 또는 비공개 환경변수를 사용합니다. 저장소 루트에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe backend/scripts/check_deployment.py --api-url https://candyaflex-edu-api.onrender.com --origin https://candyaflex-edu-agent-hub.vercel.app
```

이 검사는 GPT를 호출하거나 데이터를 쓰지 않습니다. 전체 목록을 페이지별로 받아 고유 ID와 요약의 건수·기간·수치를 독립 대조합니다. 검사 중 다른 사용자가 기록을 변경하면 불일치로 중단할 수 있으므로 변경을 마친 뒤 다시 검사합니다. 비공개 출력 경로는 `.local/verification/deployment-readiness.json`입니다. 실패 종료를 성공 증빙으로 취급하지 않습니다.

실제 POST→PUT→DELETE, GPT 생성, 브라우저 새로고침은 위 현장 시연 또는 날짜가 명시된 비공개 실행 기록에서 따로 확인해야 합니다. 자동 테스트 통과가 실제 운영 성공이나 공식 100점을 뜻하지 않습니다.
