# 월별 수업 블록

월별 화면은 비공개 Firestore의 교육계획(`plans`)과 실제 교육 기록(`data`)을 읽습니다. 접속 키가 없는 탭에서는 일정이 없는 것으로 표시하지 않고, **접속 키 연결** 안내를 표시합니다. 연결이 확인되면 선택 연도의 월별 블록을 다시 불러옵니다. 실패 후에도 ‘불러오는 중’ 표시가 남지 않습니다.

교육계획이 있는 달은 진행 예정 회차·날짜 수와 예정 교육시간을 우선 보여 줍니다. 실제 교육 실적은 별도 문구로 표시합니다. 완료·보류·대면 폐강·Zoom 대체 상태를 유지하며, 폐강된 원래 시간과 대체 시간을 실적에 합산하지 않습니다.

처음 열 때는 한국 시간의 현재 월에 보유 자료가 있으면 그 달을 선택합니다. 다른 연도나 월은 사용자가 선택할 수 있습니다. 일자별 계획 카드에 날짜·시작/종료 시간·지역·장소를 명시합니다. 원본 계획서와 온라인 시간표의 출처도 펼쳐 확인할 수 있습니다.

같은 날짜와 시간의 별개 수업은 각 일정 ID로 보존합니다. 이미 등록된 계획을 다시 생성하지 않으며, 운영자료와 원본 계획서는 공개 GitHub에 포함하지 않습니다.
# 계획서와 교육 실적 연결

월별 계획 카드에서 `연결된 실적 보기`를 누르면 해당 날짜와 과목으로 교육 실적 관리 화면을 조회합니다. 실적의 원본 시간표·인원·승인 정보는 유지하며 계획 시간과 합산하지 않습니다.

기존 실적이 연결되지 않은 계획의 `실적 등록 준비`는 날짜·시간·장소·내용을 채운 **저장 전 초안**을 엽니다. 실제 교육생 수는 직접 입력해야 하며 실제 실시 확인을 체크해야 저장됩니다. 계획 인원이나 승인 상태를 자동 복사하지 않습니다. 이 계획 ID로 저장한 실적이 있으면 기존 기록을 표시합니다.

여러 원문에서 동일한 장소·날짜·시간·과목이 겹치는 경우에는 출처를 함께 보존합니다. 과목이 다르거나 날짜·시간 열이 밀린 행은 별도 항목을 보존하고 `원문 확인 필요`로 표시합니다. 이 경우 보류는 폐강이 아니며 등록 초안 생성은 제한합니다. 같은 날짜라도 시간이 다른 수업과 사용자가 별개로 확인한 수업은 각각 유지합니다.

`교육 내용·출처 보기`에서 HWP 표·행 또는 PDF 페이지, 원문별 내용과 형식 정리 내역을 확인할 수 있습니다. 실제 운영 원본과 추출 데이터는 비공개 저장소에만 보관합니다.
