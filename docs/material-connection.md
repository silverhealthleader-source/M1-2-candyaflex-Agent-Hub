# 교재 링크 연결과 접속 키

개인 접속 키는 현재 탭의 세션에 보관합니다. 새 탭이나 만료된 세션에서 키 없이 교재 저장을 요청하면 서버는 401을 반환합니다. 이는 비공개 교육자료를 보호하기 위한 정상적인 인증 검사입니다.

기존 화면은 오류를 교재 입력 모달 뒤의 토스트에만 표시했습니다. 이제 저장 오류를 입력창 안에서 보여 주며, 인증이 필요하면 **접속 키 연결** 버튼을 제공합니다. 입력 내용은 유지됩니다. 연결 설정의 **연결하기**는 실제 서버 인증 성공을 확인한 뒤 닫히고, 사용자가 요청했던 교재 저장을 한 번 이어갑니다. 인증 실패 시 연결 설정 안에 오류를 표시합니다.

저장 중에는 버튼을 잠그고 **저장 중…**을 표시합니다. 저장 후 해당 과목으로 검색해 결과를 보여 줍니다. 저장은 성공했지만 목록 갱신에 실패한 경우에는 저장 실패로 안내하지 않습니다.

공유 링크는 `https://` 주소를 사용합니다. Canva 단축 링크도 허용하며 원본 Canva의 공유·로그인 조건은 유지합니다. 접속 키를 공개 코드나 URL에 넣지 않습니다.
