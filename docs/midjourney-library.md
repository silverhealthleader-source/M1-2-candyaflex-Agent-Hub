# 미드저니 입문→숙련 교재

완성된 PowerPoint 교재 4개를 ‘미드저니 입문→숙련’ 과목으로 등록했습니다.

| 과정 | 슬라이드 수 |
| --- | ---: |
| PART 1 · 초보자 | 29 |
| PART 2 · 중급 | 28 |
| PART 3 · 숙련자 | 26 |
| PART 4 · 동화·시화 삽화 제작자 | 29 |
| 합계 | 112 |

허브의 **동화책·스토리텔링 → 미드저니 입문→숙련 교재**에서 PART 1~4 버튼을 누르면 교재 자료실로 이동해 선택한 과정의 **PDF 슬라이드 열람 창**을 바로 엽니다. 이전·다음 버튼 또는 쪽 번호로 29·28·26·29장을 각각 볼 수 있습니다. 연결 전이면 ‘연결 설정’에서 기존 접근키를 입력하면 선택한 교재 열기를 이어갑니다. 자료실의 검색창에서도 ‘미드저니’를 검색할 수 있습니다.

홈의 과정 버튼은 웹 열람용 PDF를 우선 표시합니다. 교재 자료실에는 **PowerPoint 원본**과 **PDF 보기** 버튼을 함께 제공합니다. 다운로드한 `.pptx`를 Microsoft PowerPoint에서 열어 수업·편집에 사용합니다. 원본은 기존 교재 항목에 첨부하므로 교재 4개가 중복 표시되지 않습니다. 인증이 필요한 `GET /api/materials/{id}/original`에서 올바른 PPTX MIME과 첨부 다운로드 응답을 제공합니다.

웹 열람용 PDF는 가로 16:9로 준비했습니다. 원본 디자인을 렌더링한 이미지 기반 PDF이므로 본문 텍스트 선택·검색은 지원하지 않습니다. 편집 가능한 PPTX 원본도 비공개 파일 보관소와 로컬에 보관합니다. 교재 본문·원본 파일·접근키는 공개 저장소에 포함하지 않습니다.

PDF는 기존 `materials`·`material_files` 구조에 비공개로 저장합니다. 기존 파일 검증·인증·부분 응답 방식을 그대로 사용하며, 교육 실적 데이터는 변경하지 않습니다. `subject`·`part` URL 매개변수에는 과정 정보만 포함되며 인증 정보는 포함되지 않습니다.

비공개 PDF는 Mozilla PDF.js 6.4.299를 사이트에 포함해 페이지별로 표시합니다. 브라우저 기본 PDF 플러그인이 없어도 ‘이전/다음’과 쪽 번호로 이동하며 PDF를 내려받을 수 있습니다. 라이브러리는 사이트에서 직접 제공하고, 교재를 외부 변환 서비스에 보내지 않습니다. PDF.js의 Apache-2.0 라이선스는 `frontend/assets/vendor/pdfjs/LICENSE`에 포함합니다.
