발표 전에 준비해요

  1. 교육 사이트 연결

    강사 화면의 연결 설정에서 기존 개인 접속 키를 입력합니다. 같은 탭의 발표 화면과 실제 시연 창이 연결을 공유합니다.

    강사 화면으로 이동
  2. 실제 증빙 화면 준비

    공개 웹에는 운영 캡처가 없습니다. 비공개 제출 ZIP을 풀고 screenshots 폴더의 PNG 13장을 선택하세요. 이미지는 이 브라우저 메모리에서만 표시하며 서버에 전송하지 않습니다. 캡처가 포함된 비공개 발표 ZIP은 바로 열어도 됩니다.

    실제 화면은 각 장의 ‘실제 화면 실행’으로도 열 수 있습니다.

  3. 발표 방식 선택

    필수 시연은 10장, 전체 설명은 18장입니다. N은 메모, F는 전체 화면, Home·End는 처음·마지막 장입니다. 캡처를 누르면 확대합니다.

키는 발표 자료·URL·공개 캡처에 넣지 않습니다. 새로 불러온 캡처는 새로고침 시 해제됩니다.
